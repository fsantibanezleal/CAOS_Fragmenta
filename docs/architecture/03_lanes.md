# The three lanes

## Offline is canonical

Training, the hidden-width sweep, the seed sweep, the ten-fold leave-one-site-out matrix and the
whole benchmark run before release, in a pinned Python environment, against a separately published
engine package.

Nothing here runs at deploy time and nothing here runs in a browser.

## Replay is the default evidence

The web reads committed, content-addressed artifacts and computes nothing from raw data. Every number
on a screen traces to a file whose hash the release gate checked.

## Live is the workbench

The closed-form models are reimplemented in TypeScript so that changing a burden moves the curve
rather than reloading a page. Without this the App would be a replay viewer with sliders that do
nothing.

**Parity is a gate, not a hope.** The parity test scores the browser engine against the baked numbers
point for point: the mean size on 91 blasts, the regression on 123, the group router on 123, both
distribution curves across all 241 grid points, the geometry reconstruction, and the refusals. A
divergence fails the build.

Two implementations of one equation drift the moment nobody checks, and the symptom is a chart that
is subtly wrong and entirely plausible.

The gate earned itself on its first run by catching the non-finite-JSON defect described in
[the data contracts](02_data-contracts.md).

### One trap the parity gate is aimed at

The uniformity index leading term is 2.2 minus 14 times the burden over the diameter, with the burden
in METRES and the diameter in MILLIMETRES. Read as the dimensionless burden-to-diameter ratio the
corpus tabulates, which is a thousand times larger, the term becomes 2.2 minus 382 and the index goes
to about -380.

The test asserts the index lands in a physical band on every real blast, and separately asserts that
the degenerate control returns exactly zero, which is correct rather than broken: the index is linear
in the charge length and those designs have no charge column.

## The lane gate

Which lane a case runs in is a MEASUREMENT, recorded in its manifest with the numbers behind it, not
a label somebody chose. Every case in this product is classified live, because every model here is
closed form or a small exported prediction and the artifacts are small.
