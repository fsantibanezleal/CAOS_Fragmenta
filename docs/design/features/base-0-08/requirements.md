# Requirements: release 0.08.000 on shell 0.15.0 and template 0.08.002

Status: live

The release was sized and its contract catalog written before its units were built (ADR-0075, ADR-0080); these
requirements were written after the units, on 2026-10-18, from their code, tests and reports, so each names the test
that already holds it (retroactive for this release). EARS.
