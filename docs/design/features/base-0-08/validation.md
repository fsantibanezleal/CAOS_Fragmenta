# Adversarial validation: release 0.08.000

For each requirement of [`requirements.md`](requirements.md), the check that tries to break it: what was planted or
refuted, and the test that plants it. Every requirement has a row. The rows of RT-001 to RT-003, EV-002, EV-003, PG-001,
PG-002, CT-003 and BR-001 were added by unit V3 (CAOS_Fragmenta#33): their gates, ordinary tests, prove the requirement
passes, and each row now plants the defect it forbids in a throwaway copy and shows that the same gate fails.
