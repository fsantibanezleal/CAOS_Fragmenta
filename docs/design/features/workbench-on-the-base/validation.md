# Adversarial validation: the App on the shared base

For each requirement of [`requirements.md`](requirements.md), the check that tries to break it: what was planted, and the
test that plants it, in a throwaway copy of the repository, with the requirement's own gate run on the copy. The gates
that need a built site and a browser (the shell gate and the product's browser gate) are local-only: they skip where node,
the installed frontend or a Playwright browser is absent, and the checks job installs none of them. Requirements that
share a plant share one build and one gate run, said in each row.
