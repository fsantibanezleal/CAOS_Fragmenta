# Requirements: the bake, the cases and the release gate

Retroactive (written 2026-10-05; the code is 0.01.000 to 0.05.001). EARS (Mavin et al., RE'09,
doi:10.1109/RE.2009.9). Every requirement names the test that fails when it is violated.

| ID | Requirement | Gate |
|---|---|---|
| BK-001 | WHEN the bake finishes, THE release gate SHALL re-read every artifact and recompute every digest against its own and the index's. | `tests/test_pipeline.py::test_the_committed_bake_passes_its_own_release_gate`, `tests/test_pipeline.py::test_every_artifact_digest_matches_its_content` |
| BK-002 | IF the benchmark artifact is edited after the bake, THEN THE release gate SHALL fail. | `tests/test_pipeline.py::test_the_release_gate_rejects_an_edited_benchmark` |
| BK-003 | THE bake SHALL have been made from the corpus the installed engine ships. | `tests/test_pipeline.py::test_the_bake_was_made_from_the_installed_corpus` |
| BK-004 | THE case matrix SHALL hold sixteen cases across six categories, each bilingual, each stating why it is in the matrix, each with at least six variants. | `tests/test_pipeline.py::test_sixteen_cases_across_six_categories`, `tests/test_pipeline.py::test_every_case_is_bilingual`, `tests/test_pipeline.py::test_every_case_states_why_it_is_in_the_matrix`, `tests/test_pipeline.py::test_every_case_carries_at_least_six_variants` |
| BK-005 | THE method-by-case matrix SHALL have no hole: every prediction cell SHALL hold a value or a reason. | `tests/test_pipeline.py::test_the_method_by_case_matrix_has_no_holes`, `tests/test_pipeline.py::test_every_prediction_cell_has_a_value_or_a_reason` |
| BK-006 | WHEN a control case is baked, THE control SHALL fire and pass: the geometry control abstains, the degenerate designs are refused by every arm, the positive control recovers its truth, the extrapolation control is stamped. | `tests/test_pipeline.py::test_the_geometry_negative_control_fires_and_passes`, `tests/test_pipeline.py::test_the_degenerate_negative_control_is_refused_by_every_arm`, `tests/test_pipeline.py::test_the_positive_control_recovers_its_own_truth_exactly`, `tests/test_pipeline.py::test_the_extrapolation_control_stamps_every_prediction` |
| BK-007 | IF a control never fires, THEN THE suite SHALL catch it. | `tests/test_pipeline.py::test_a_control_that_never_fires_would_be_caught` |
| BK-008 | WHEN a real campaign is baked, THE learned arms SHALL have been fitted without its site, and THE leakage assertion SHALL fail when that is violated. | `tests/test_pipeline.py::test_every_real_campaign_withheld_its_own_site_from_the_learned_arms`, `tests/test_pipeline.py::test_the_leakage_assertion_actually_fails_when_violated` |
| BK-009 | THE geometry report and the absolute pattern SHALL be baked for every real campaign and every reconstructable blast. | `tests/test_pipeline.py::test_the_geometry_report_is_baked_for_every_real_campaign`, `tests/test_pipeline.py::test_every_reconstructable_blast_carries_its_absolute_pattern` |
| BK-010 | THE score blocks SHALL never report a bare variance figure, and every scoreable case SHALL carry a null model. | `tests/test_pipeline.py::test_no_score_block_reports_a_bare_variance_figure`, `tests/test_pipeline.py::test_every_scoreable_case_carries_a_null_model` |
| BK-011 | IF a case has no measurements, THEN ITS artifact SHALL say so rather than score zero. | `tests/test_pipeline.py::test_a_case_with_no_measurements_says_so_rather_than_scoring_zero` |
| BK-012 | THE variant curves SHALL move in the physically correct direction. | `tests/test_pipeline.py::test_the_variant_curves_move_in_the_physically_correct_direction` |
| BK-013 | WHEN the same case is baked twice in one environment, THE artifacts SHALL be byte-identical, and a re-bake SHALL reproduce the committed numbers to the named tolerance. | `tests/test_pipeline.py::test_rebaking_the_same_case_twice_here_is_byte_identical`, `tests/test_pipeline.py::test_rebaking_reproduces_the_committed_numbers_to_tolerance` |
| BK-014 | THE bake SHALL ship one models file per campaign plus the corpus, each case SHALL point at its own training scope, and THE portable models SHALL reproduce the fitted models. | `tests/test_pipeline.py::test_there_is_one_model_file_per_campaign_plus_the_corpus`, `tests/test_pipeline.py::test_every_case_points_at_the_model_file_of_its_own_training_scope`, `tests/test_pipeline.py::test_the_portable_models_reproduce_the_fitted_models_at_every_fixture` |
